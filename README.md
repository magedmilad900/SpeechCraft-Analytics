# OratorPulse — Rubber-Hose-Inspired Speech Detective

A Streamlit demo with a warm vintage cartoon aesthetic inspired by early rubber-hose animation.

## Features
- Cream paper background with bold black outlines and coral, teal, blue, and orange accents
- Writing-style inspection for word count, sentence length, selected phrases, and repetition
- Rule-based chat helper
- TXT and CSV import

## Run
```bash
pip install -r requirements.txt
streamlit run Application.py
```

## Limitations
This demo is not a trained AI detector and cannot reliably establish authorship. It does not yet include audio transcription, pitch analysis, or pause analysis.
